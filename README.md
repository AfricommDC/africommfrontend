# Africomm Frontend

Welcome to the Africomm Frontend repository! This is the web application for Africomm, a community-focused organization dedicated to empowering individuals and building impactful partnerships across Africa.

## About This Project

The Africomm website is a modern web application that serves as the digital home for Africomm's mission. It provides information about our organization and creates avenues for people to get involved through volunteering and donations.

### What You Can Do On This Site

- **Learn About Us** - Discover who Africomm is and our mission
- **Understand Our Model** - Learn about our organizational approach
- **Get Involved** - Find ways to volunteer and support our cause
- **Make a Donation** - Contribute financially to our initiatives
- **Contact Us** - Reach out with questions or inquiries

## Getting Started

### Prerequisites

Make sure you have the following installed on your computer:
- Node.js (version 18 or higher)
- npm (comes with Node.js)

### Installation Steps

1. **Clone the repository**
 ```bash
   git clone <repository-url>
 ```
   then 

```bash
   cd africommfrontend
 ```

2. **Install dependencies**

 ```bash
   npm install
 ```

### Running the Application

To start the development server and view the site locally:

```bash
npm run dev
```

Open your browser and go to `http://localhost:5173` to see the application.

### Building for Deployment

To create a production-ready version:

```bash
  npm run build
```

To preview the production build locally:

```bash
npm run preview
```

### Code Quality

To check for any code quality issues:

```bash
npm run lint
```
